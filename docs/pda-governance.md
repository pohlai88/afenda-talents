Important governance for Malaysia

Assessment answers, profiles and placement recommendations are personal data. Malaysia’s data-protection framework requires organisations processing personal data in commercial transactions to follow principles covering notice, choice, security, retention, integrity and access.

Malaysia’s April 2026 guidance also treats automated evaluation of workplace performance, reliability, behaviour, preferences or interests as profiling. Where AFENDA Talent uses automated scoring or AI, the candidate should receive a clear privacy notice, the risks should be assessed, the purpose should be limited, and human involvement must be genuine rather than merely approving an automatic result.

Employment assessments should also be demonstrably job-related and monitored for unfair exclusion. A test can appear neutral while still disproportionately excluding a group, so assessment outcomes and selection rates should be reviewed regularly.

For AFENDA Talent, the clean implementation would separate this into four records: Candidate Baseline, Assessment Evidence, Probation Observation, and Final Placement Comparison. This prevents the system from treating a pre-employment personality result as permanent truth.
